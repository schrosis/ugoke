# プロジェクトの信頼

ugoke のコマンドは、プロジェクトの設定と定義を読み、プラグインとスクリプトを自分の権限で動かします。そのため、初めて使うプロジェクトでは、ファイルを読む前に、信頼するかを聞きます。

```text
? Do you trust the files in /home/user/my-project? ugoke reads its configuration and runs its plugins and scripts as you (y/N)
```

## 聞くコマンド

プロジェクトを読むコマンドが聞きます。

- [`ugoke run`](commands/run.md)
- [`ugoke attach`](commands/attach.md)
- [`ugoke cancel`](commands/cancel.md)
- [`ugoke inbox`](commands/inbox.md)
- [`ugoke log`](commands/log.md)
- [`ugoke validate`](commands/validate.md)
- [`ugoke docs`](commands/docs.md)
- [`ugoke schema`](commands/schema.md)

[`ugoke daemon`](commands/daemon.md) は、プロジェクトを読まないので、聞きません。

## 答え

| 答え                   | 動き                                                             |
| ---------------------- | ---------------------------------------------------------------- |
| `y`                    | プロジェクトを信頼の記録に足し、コマンドを続けます               |
| `n`、Enter だけ        | 何も読まずに、1 で終わります                                     |
| 答える前に入力が終わる | 何も読まずに、1 で終わります                                     |
| Ctrl+C                 | 何も読まずに、130 で終わります                                   |

- `y` 以外では、信頼の記録は変わりません
- 信頼の記録に書けないときは、理由を表示し、何も読まずに 1 で終わります
- [信頼の記録](#信頼の記録)を読めないときは、聞かずに、理由を表示して 1 で終わります
- 一度信頼したプロジェクトでは、もう聞きません。中のファイルが変わっても同じです

## 信頼するもの

信頼するのは、[プロジェクトのルート](../guide/project.md#プロジェクト)です。

- プロジェクトのサブディレクトリで実行しても、同じルートを使います
- 信頼したプロジェクトの中に、別の `.ugoke` を持つディレクトリがあれば、それは別のプロジェクトです。そこで実行すると、別に聞きます
- シンボリックリンクを通って来ても、同じプロジェクトとして扱います

[`ugoke init`](commands/init.md) で作ったプロジェクトは、聞かずに信頼します。

## 誰も答えられないとき

次のときは、聞かずにコマンドを続けます。信頼の記録は、読まず、変えません。

- `--from-ai` を付けたとき
- 標準入力か標準エラーが、ターミナルでないとき。たとえば、パイプ、スクリプト、CI です

> [!WARNING]
> このときは、信頼していないプロジェクトでも、プラグインとスクリプトが動きます。AI エージェントや CI から使うときは、信頼できるプロジェクトでだけ実行してください。

## 常駐プロセス

常駐プロセスは、信頼の記録を見ません。コマンドが[登録したプロジェクト](commands/daemon.md#プロジェクトの登録)を、そのまま動かします。

- 登録したプロジェクトのプラグインは、常駐プロセスを起動するたびに読み込みます
- 信頼の記録から外しても、登録は残ります

## 信頼の記録

信頼したプロジェクトは、ugoke の状態ディレクトリの `trusted-projects.json` に記録します。たとえば、`~/.local/state/ugoke/trusted-projects.json` です。

```json
[
  "/home/user/my-project"
]
```

- 信頼をやめるときは、このファイルからプロジェクトの行を消します
- ファイルがまだないときは、どのプロジェクトも信頼していないものとして扱います
- ファイルを読めないときは、聞かずに、理由を表示して 1 で終わります。たとえば、行を消したあとに `,` が残ったときです。ファイルを直すか、消してください。消すと、どのプロジェクトでも、もう一度聞きます
