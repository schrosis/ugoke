# ugoke init

```text
ugoke init [options]
```

今のディレクトリに `.ugoke` を作り、ugoke のプロジェクトにします。今のディレクトリが、[プロジェクトのルート](../../guide/project.md#プロジェクト)になります。

## オプション

| オプション     | 内容               |
| -------------- | ------------------ |
| `-h`, `--help` | ヘルプを表示します |

## 作るファイル

| ファイル                      | 内容                                                                                   |
| ----------------------------- | -------------------------------------------------------------------------------------- |
| `.ugoke/config.yaml`          | [プロジェクトの設定](../config.md)です。プラグインの書き方を、コメントで案内します     |
| `.ugoke/workflows/hello.yaml` | 試すためのワークフロー `hello` です。文字を表示するだけです                            |
| `.ugoke/schemas/`             | [ugoke schema](schema.md) と同じ JSON Schema です                                      |

作ったあとに、次にすることを表示します。

## 動き

- `.ugoke` がもうあるときは、何も作らずに 1 で終わります。中のファイルは変えません
- 途中で失敗したときは、作った `.ugoke` を消して、1 で終わります
- ほかのプロジェクトの中でも作れます。そのときは、近い方の `.ugoke` がプロジェクトになります

## 終了ステータス

- `0`: プロジェクトを作った
- `1`
  - `.ugoke` がもうある
  - ファイルを作れなかった
