# ugoke

```text
ugoke [options] [command]
```

ugoke のコマンドの入り口です。コマンドを指定しないと、ヘルプを表示し、終了ステータスは 1 です。

## オプション

| オプション        | 内容                   |
| ----------------- | ---------------------- |
| `-V`, `--version` | ugoke のバージョンを表示します |
| `-h`, `--help`    | ヘルプを表示します     |

`ugoke help <command>` でも、コマンドのヘルプを表示します。

## 終了ステータス

- `0`: 成功した
- `1`
  - エラーがあった
  - コマンドを指定しなかった
  - 知らないコマンドを指定した
  - 引数が足りない
  - プロジェクトを信頼しなかったか、信頼の記録を読めなかった（「[プロジェクトの信頼](../trust.md)」）
- `130`: プロジェクトを信頼するかの確認で、Ctrl+C を押した

ワークフローを実行するコマンドは、ほかの値も使います。たとえば「[ugoke run](run.md#終了ステータス)」です。
