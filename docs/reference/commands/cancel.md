# ugoke cancel

```text
ugoke cancel [options] [workflow-id]
```

プロジェクトの実行を取り消します。待機ステップの待ちと、実行中のスクリプトや AI を止めます。順に読む説明は、ガイドの「[ワークフローを実行する](../../guide/run.md)」にあります。

## 引数

| 引数            | 内容                                                                                     |
| --------------- | ---------------------------------------------------------------------------------------- |
| `[workflow-id]` | 実行の ID です。書かなければ、プロジェクトの実行を一覧にして、ターミナルで選んでもらいます |

## オプション

| オプション              | 内容                                                                     |
| ----------------------- | ------------------------------------------------------------------------ |
| `--address <address>`   | 使う Temporal Server のアドレスです                                      |
| `-h`, `--help`          | ヘルプを表示します                                                       |

使う Temporal Server の決め方は、[`ugoke run`](run.md#使う-temporal-server) と同じです。

## 動き

- 選べるのは、このプロジェクトから始めた、まだ終わっていない実行です
- ほかのプロセスが追いかけている実行も取り消せます。追いかけているプロセスには、取り消したことが表示されます
- 取り消す前に実行が終わっていたときは、そのことを表示します
- 別のバージョンの ugoke が始めた実行と、バージョンを記録していない実行は、取り消す代わりに強制終了します。一覧では `(started by another version of ugoke)` と添えます。実行中のスクリプトや AI は、少しあとに止まります

## 終了ステータス

- `0`
  - 実行を取り消したか、強制終了した
  - 取り消す前に終わっていた
  - 取り消せる実行がなかった
- `1`
  - 実行を選ばなかった
  - 指定した実行がない
  - [プロジェクトの設定](../config.md)に問題がある
  - サーバーの準備に失敗した。たとえば、常駐プロセスが動いていない
  - 暗号化の鍵が壊れている
  - 取り消しに失敗した
- `130`: Ctrl+C で終了した
