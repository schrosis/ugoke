# ugoke log

```text
ugoke log [options] <workflow-id>
```

プロジェクトの実行の進み具合を表示します。終わった実行も表示できます。順に読む説明は、ガイドの「[ワークフローを実行する](../../guide/run.md#進み具合を見る)」にあります。

## 引数

| 引数            | 内容                                                           |
| --------------- | -------------------------------------------------------------- |
| `<workflow-id>` | 実行の ID です。`ugoke run` や `ugoke inbox list` が表示します |

## オプション

| オプション            | 内容                                                                                  |
| --------------------- | ------------------------------------------------------------------------------------- |
| `--tail <lines>`      | これまでの進み具合の、最後の行だけを表示します。0 以上の整数です                      |
| `--follow`            | 実行が終わるまで、進み具合を表示し続けます                                            |
| `--json`              | 人向けの表示の代わりに、出来事ごとに 1 行の JSON を出します。ステップの出力も含みます |
| `--address <address>` | 使う Temporal Server のアドレスです                                                   |
| `-h`, `--help`        | ヘルプを表示します                                                                    |

## 動き

- 表示できるのは、このプロジェクトが記録した進み具合です
- 表示の形は `ugoke run` と同じです。ステップの標準エラーも、標準出力に表示します
- `--tail` は、記録してある分だけに効きます。`--follow` と一緒に使うと、最後の行を表示してから、続きを表示します
- `--follow` は、実行がまだ動いているかを Temporal Server に聞きます。使う Temporal Server の決め方は、[`ugoke run`](run.md#使う-temporal-server) と同じです
- `--follow` を付けないときは、Temporal Server を使いません。常駐プロセスが動いていなくても、表示できます
- `--follow` は、Ctrl+C で止まります。実行は止まりません
- `--json` の行の種類は、「[プログラムから使う](../from-ai.md#行の種類)」の `stepStarted` と `stepFinished` に、ステップの出力の `stepOutput` が加わったものです

## 終了ステータス

- `0`
  - 進み具合を表示した
  - `--follow` を Ctrl+C で止めた
- `1`
  - 実行の進み具合が記録されていない。`--follow` を付けたときは、実行も動いていない
  - プロジェクトが見つからなかった
  - [プロジェクトの設定](../config.md)に問題がある。`--json` だけのときは、設定を読みません
  - `--follow` で、サーバーの準備に失敗した。たとえば、常駐プロセスが動いていない
  - `--follow` で、追いかけている途中に、サーバーが答えなくなった
  - `--follow` で、暗号化の鍵が壊れている
